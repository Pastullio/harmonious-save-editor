Harmonious Save Editor

A save editor for No Man's Sky on PC (Steam and GOG). Edit your traveller, ships, corvettes, bases and inventories. Keep every ship you've owned. Find places by their portal glyphs and warp there. Build in Blender and send it straight into your save.

Getting started

The desktop app is one small program with no installer. It finds your saves on its own and writes straight back to the game's folder.

  1. Download Harmonious Save Editor.exe from the dist folder on GitHub. Put it anywhere you like.
  2. Run it. Windows SmartScreen warns the first time because the program isn't code-signed. Choose More info, then Run anyway.
  3. Pick a save. The editor lists your save slots from %APPDATA%\HelloGames\NMS, newest first. Click one to open it.
  4. Let the item library build. The first time, the app reads item names, icons and descriptions from your No Man's Sky install. It takes about a minute and happens once (and again after game updates).
  5. Make your changes on any page. The sidebar shows Unsaved changes while you have some.
  6. Close the game, then press Save to game at the bottom of the sidebar.

The window

  • Sidebar: the save's name and play time at the top, then the find box, the sections in their groups, links to other tools, and the save button.
  • Buttons at the very bottom: open the save folder, back up all saves, show backups, customise the sidebar, light or dark mode, Exit, and About (version, links and credits).
  • Leaving with unsaved changes: closing the window or pressing Exit asks whether to Save & exit, Exit without saving or keep editing. With nothing unsaved the window just closes.
  • Your own sidebar: the customise button (lines with a pencil) lets you drag pages up and down or into another group, move whole groups with their arrows, and hide pages you don't use with the eye. Hidden pages are still found with Find anything. Reset to default puts it all back; Done finishes.
  • The "?" signs beside headings and fields show a short explanation when you point at them.

Updates

When a new version is out, the app offers it once. Accept and it downloads the new version, checks it, swaps itself over and restarts, showing its progress while it works. Nothing needs reinstalling. Once it's back it shows what changed since the version you had. About shows which version you're using, and What's new there lists the recent changes again.

Pinning it to the taskbar

The editor opens in its own window, centred on your screen, with its own taskbar button. The window uses WebView2, the Edge engine built into Windows 10 and 11; without it the editor opens an Edge window instead. Right-click the taskbar button and choose Pin to taskbar. A pin from an older version (before the editor had its own window) shows as a separate button: unpin it and pin the new one. You can also right-click Harmonious Save Editor.exe in File Explorer, choose Show more options, then Pin to taskbar.

Where exported files go

Everything you export (ship and multi-tool backups, .nmsship and .so files, place cards) is saved in Documents\Harmonious Save Editor\Exports, and the folder opens with the new file selected. Nothing is overwritten: a second file with the same name gets (2) added.

Your saves are safe

The editor is built never to lose data. Here's everything it does to protect your saves, and how to get an old version back.

  • A backup every time you save. Before replacing a save, the app copies the current pair of files to %LOCALAPPDATA%\HarmoniousSaveEditor\backups\<account>\<time>_saveN. The clock-arrow button at the bottom of the sidebar (Show backups) opens that folder.
  • Back up all saves zips every slot into Documents\Harmonious Save Editor backups.
  • Checked before writing. The new save is decoded again and compared with what's in the editor. If anything differs, nothing is written.
  • Nothing changes by accident. A save you open and save without edits comes out identical: key order, number spelling and special bytes are all kept.
  • New saves from the game. If the game writes a newer save while the editor has one open, a card offers to open the new one. It asks first if you have unsaved edits.
  • Your ships are kept too. The Dock Yard's Hangar keeps a copy of every ship in every save you open, so even a deleted ship can come back.
  • Private. The app only listens on your own PC (127.0.0.1) with a new random key each run, so web pages can't reach it. It closes a few seconds after its window does.

Getting an old save back

  1. Close No Man's Sky.
  2. Press Show backups and open the folder with the time you want.
  3. Copy both files (saveN.hg and mf_saveN.hg) into your save folder (the folder button at the bottom of the sidebar opens it), replacing the current pair.
Steam CloudSteam can put back an older copy of a save if it syncs before the game starts. If an edit seems to vanish, let Steam finish syncing, or choose the local copy when Steam asks.

Overview

Your traveller at a glance: who you are, what you're flying, where you are, and what you've done.

  • Traveller cards: your portrait, current ship, multi-tool and location. Give your traveller a picture with Choose a screenshot (from your in-game photos) or Image file. Click the ship or multi-tool to jump to it.
  • Location: galaxy, system, portal glyphs and galactic address. Coordinates and warp takes you to the Coordinates page.
  • Quick fixes for every inventory in the save at once: Repair all technology, Recharge all technology and Fill every stack.
  • Journey: planets and systems discovered, creatures, words learned, warps, distance walked and flown, and more.
  • Currencies: units, nanites and quicksilver. Type a number or use +1M, +100M and Max.
  • Save name: how this save is named in the game's load menu.

Shipwright

Corvette builds, done right: parts in the order the game reads them, checks for the mistakes that break a build, and whole builds in and out in one go.

Your corvettes

The list on the left shows each corvette with its slot and part count. Add corvette makes a new one in an empty ship slot with a starter build; Delete corvette removes one.

The picked corvette's picture sits beside its name: its Blender render, or a hologram of its parts until it has one. Change picture uses a screenshot instead.

Build check

  • Cockpits: the first two in the list are the camera cockpit and the boarding cockpit.
  • Landing bay: the first one is where you beam up. If it's scaled too small, beam-up won't work, and the check says so.
  • Part order: performance parts listed late can lose stats or misbehave. Tune up fixes the order (TAZmd's documented priority order; cockpits and the beam-up bay stay put). Tick Tune up when pasting or loading to do it every time. The gear beside Tune up sets your own order: move the groups with the arrows or drag them, then Save; Standard order puts TAZmd's back. A dot on the gear means your own order is in use.
  • Stacked parts: parts sitting exactly on top of an identical one, with a one-click fix.

Builds in and out

  • Copy all and Paste all move a whole build between corvettes, saves or other tools such as TAZ's. Pasting replaces only the parts; the corvette keeps its name, class, inventory and owner.
  • Load file and Save as… read and write builds as files.
  • Load from a .blend… reads a Charon Forge corvette file from Blender. See Blender.
  • Parts list: search, select (click, Ctrl+click, Shift+click), move parts Up and Down, copy or delete them.

LiveLink

Turn LiveLink on for a corvette and each time you save in Blender, the build lands in your save. Set it up on the Blender page.

Coordinates

Find a place by its portal glyphs or galactic address, see what your save knows about it, and warp there.

Choosing a destination

  • You are here shows your galaxy, system, portal glyphs and galactic address, with the planet you're on as a small turning globe in its biome's colours (and its moon going round it when the save shows one), or, in space, the star with the system's planets and moons going round it. Start from here copies it into the destination.
  • Portal glyphs: click the sixteen glyphs to type a portal code. Delete last glyph and Clear fix mistakes.
  • Portal code, galactic address and galaxy fields stay in step as you type any of them. Galactic addresses are what a signal booster shows.
  • Your places picks one of your bases or space stations.
  • Make a glyph banner opens the Portal Glyph Banner tool with this address.

Favourite places

  • Star a place to keep it: the star by the system's name and by each planet in the planet table (a planet is kept under its own name, with its system as the note), the Add to favourites star next to Warp here, the stars beside places and bases in a system, the star by You are here, and Add to favourites on a base or settlement in Bases. A filled star means it's already a favourite; click it again to remove it.
  • Favourite places lists them with their glyphs. Go here loads the glyphs and galaxy into the destination, ready to warp. Edit renames a place, changes its kind, adds a note or removes it.
  • They're kept outside your saves, in Documents\Harmonious Save Editor\Favourite places.json, so every save can use them. A base keeps its spot on the planet, so Arrive here works from a save that doesn't have it.
  • Export saves the list to a file to share; Import adds places from a shared file, skipping ones you already have.

About this system

  • Names players gave: when you or another traveller renamed the system or a planet, and the save has that name (it keeps the names of places you've visited), it's shown first, with the game's own name and who named it beside it.
  • Nickname next to a system or any planet gives it a name of your own, shown only in the editor (with its name in the game beside it). It doesn't rename anything in the game: to do that, rename it in the game and upload it to the game's servers. Nicknames are kept in Documents\Harmonious Save Editor\Nicknames.json.
  • Prediction: the system's name, region, star colour, economy, conflict and planets, worked out from the address.
  • Planets: each body with its name, portal address and biome. Biomes you've seen come from your discovery records. For the rest, the biome odds show the most likely biome and its chance, from the game's own tables by star colour and galaxy type. Prime bodies (the extra ones the game adds) use their own odds.
  • From your save: whether you've been here and what you've discovered.
  • Places here: every base, teleporter and space station in the system, once each, with a star to keep it in your favourites and Arrive here on the bases you can land at.
  • Place card: Copy card, Save card or Copy as text to share the destination.

Warping

  • Warp here asks how you want to arrive: in your ship in space, aboard your freighter (it's called to the system), or at a base in the system, yours or one you've visited, on foot with your ship hovering above.
  • A favourite base picked with Go here skips the question and lands you there; Other ways to arrive brings the choices back.
  • Arrive here in Places here lands you at that base straight away.
  • Landing at a base needs to know where the system's planets are: the app learns that from any save made in that system.

Nothing changes in the game until you press Save to game; your old location is kept as your previous one.

Garage

Your ships, corvettes and multi-tools as cover art, with real 3D models from your game.

  • Cover Flow: scroll, drag or use the arrow keys. Click the centre cover to open its loadout. Switch to a Grid on the right, above the covers.
  • Filters: All, Corvettes, Starships and Multi-tools.
  • Models: ships and multi-tools are drawn from your game's own model files. Point at a cover and it spins; drag to turn it.
  • Pictures: drop an image on a cover, or use Choose a screenshot or Use an image file. Change picture goes back to the model.
  • Details under the covers: type, class, tech modules, items carried, build parts and whether it's your current ship. Open loadout jumps to its editor.

Corvettes

  • Hologram: without Blender, a corvette shows each part as a block at its real size, coloured by type (cockpit, engines and wings, weapons, shields, reactors, landing gear, bays, hull and decor).
  • Renders: Render all corvettes or Render again. The View choices switch between three-quarter, front, side, back and top. The editor remembers your choice for each build.
  • Cover settings point the app at Blender and Charon Forge, and turn automatic renders on or off.

Dock Yard

Every ship you own, build or download, in one place. Keep every version and move ships and corvettes into any save.

The Dock Yard lives in Documents\Harmonious Save Editor\Dock Yard, so it's shared by all your saves.

The three tabs

TabWhat's in it
HangarFills itself. Every ship in every save you open is copied here, and a ship you replace is copied first, so nothing is lost.
Ship storageShips you keep on purpose: files you import and ships you save from your game.
FavouritesShips you star, from anywhere in the Dock Yard.

Under the tabs: All ships, Linked folders (folders where you already keep ship files; the app only reads them) and Manage folders. To link a folder, paste its path and press Add path, or use Browse… to pick it. Add path with an empty box opens the picker too.

Doing things with a ship

A ship that's in the save you have open says Loaded, slot 2 (or whichever slot) on its cover, and loaded ships come first, in slot order. Pick a ship and the bar above the covers shows what you can do:

  • Edit ship opens it on the Starships page, ready to change. Corvettes also have Edit build, which opens their parts in Shipwright.
  • Load ship into game… for a ship that isn't in the save, then Edit ship once it's in.
  • Details opens the ship's card (versions, tags, notes, export), and Favourite stars it.

In the grid, a loaded ship's card says Loaded, slot 2 with an Edit ship button; the others have Load ship into game…. Loading puts the ship in the save you have open; press Save to game to write it to your game. From Starships, Versions in the Dock Yard comes back to the ship's card here.

Hangar versions

  • A new version is kept only when the ship itself changes: its build, model, name, class, colours or installed tech. Fuel, charge, cargo and where it's parked don't count.
  • Pick a version in the list to see it, put it in a save, export it or delete it.
  • Copies of the same version (from older editor versions) show as "seen N times". Move them to Deleted clears them out.

Using a ship

  • Load ship into game… drops a ship into an empty slot or replaces one (the replaced ship goes to the Hangar first). Corvettes bring their build.
  • A build on its own (no ship) goes onto one of your corvettes, which keeps its name and class. A .so file does the opposite: a corvette takes its tech and class and keeps its build.
  • Copy to Ship storage, Render with Blender, and export as .nmsship or .so for TAZ's tools.
  • Tags, notes, a link and a favourite star on every card. Get art from the link fetches the artwork, author and description from a listing page.
  • Import files reads .json, .txt, .nmsship, .so and Base Building App .nmsprefab files. Add this save's ships stores them all.
  • Delete moves files to the Dock Yard's Deleted folder, so they can always come back.

Exosuit

Your exosuit's technology and cargo, laid out exactly as the game shows them.

The exosuit uses all the inventory tools: Technology / Cargo / Both, unlocking slots, filling stacks, repairing, resizing and supercharged slots.

Your traveller

At the top of the page is your traveller, built from your save the way the game builds them: the head, torso, armour, gloves, legs, boots, backpack, cape and cloth you wear. It needs the game on your PC (the editor finds it).

  • Export for Blender (.glb) saves your traveller with their skeleton to Documents\Harmonious Save Editor\Exports. In Blender, use File, Import, glTF 2.0 and pose the bones.
  • Easier: in Blender's LiveLink panel, open Your traveller and press Import my traveller. It brings in the traveller from the save open in the editor and switches to Pose mode. The bones stay hidden until you need one: click a part of the body (a calf, a hand, a finger) and the bone that moves it shows, selected; press R to turn it. It turns where it joins the body. Shift+click adds another part, a click on empty space hides them again, and Show every stick in the panel shows them all. Keep the body's proportions (on by default) means bones only turn, so moving or scaling can't stretch an arm or a leg; the root bone still moves the whole traveller. Turn it off to move and scale bones freely. Ctrl+Tab goes back to Object mode, where the whole traveller moves as one. The game's helper joints (cameras, effects, attach points) are in a hidden bone collection called Helpers.
  • Save traveller files for the developer collects the materials and textures your traveller wears into a zip in Exports, for work on the real colours and textures.
  • Save the pose as a picture renders your pose to a PNG with a transparent background in the same Exports folder. If your scene has no camera, one is added looking at your traveller; move it to frame the shot you want and press the button again.
TexturesThe model comes with the game's own textures: colour, surface detail (normal maps) and which parts are metal or rough, one material per part of the outfit. They show in Blender's Material Preview and Rendered views. The colours you picked in the game (from your save) are coming in a later update; until then the parts wear the game's standard colours.

Multi-tools

Every multi-tool you own, its looks, stats and technology.

  • Pick a multi-tool from the covers. The equipped one says so.
  • Name, type (standard, royal, sentinel, atlas, staff and the rest), class, and seed, which decides its look. Generate rolls a new one.
  • Use old colours, and base stats: damage, mining and scanning.
  • Save as profile keeps the loadout as a file; Apply a profile puts one on any multi-tool. Profiles work across saves; share one by sending the file.
  • Choose parts for the cover model, Export… a .json backup, Import, and Delete multi-tool. Deleting works even when all six slots are full: the slot is left empty, the same way the game leaves one.
  • Add a multi-tool on the left, above the covers.
  • Supercharge slots above the multi-tool's technology.

Starships

Rename ships, change their looks and class, arrange and repair ship slots, and manage each ship's inventories.

Ship slots

  • Arrange: drag ships into a new order. Corvette builds, colours and your current ship move with them.
  • Close the gaps moves ships up into empty slots.
  • Problems and fixes: for example a corvette build pointing at the wrong slot. Fixes that delete something are listed last and marked.

Each ship

  • Name, type (hauler, explorer, shuttle, fighter, exotic, living ship, solar, interceptor, corvette and the special ships), class, seed with Generate, and use old colours.
  • Base stats: damage, shields, hyperdrive and maneuverability, plus ship health and shield (shared by all ships).
  • Save as profile, Apply a profile, Choose parts, and Versions in the Dock Yard for every version of the ship the Hangar has kept.
  • To the Dock Yard… asks what you want: Keep a copy stores the ship and leaves it in your game; Move it stores it in Ship storage and empties its slot (not for the ship you're flying). Put it back any time with Load ship into game….
  • Export… as a .json backup, a .nmsship (whole corvette) or a .so (the ship entry, for TAZ's tools); Import; Delete ship.

Adding and archiving

  • Add a ship: a new corvette, or a copy of one of your ships with its colours and build.
  • Archived ships: the ships the game keeps in its archive. Restore one into a slot, or Archive a ship.
  • Render corvettes makes Blender renders for the Garage.

Freighter

Your capital ship, its inventories and its fleet of frigates.

  • Name, type (capital, regular, small, tiny, pirate dreadnought), class, home seed and model seed.
  • Base stats: hyperdrive, fleet coordination, and how many base parts can go aboard.
  • Save as profile, Apply a profile, Back up to a file and Restore from a file.
  • Inventories: technology and cargo, with all the inventory tools.

Frigates

  • Each frigate: name, type, class, expeditions and damage.
  • Stats: combat, exploration, mining, trade, speed, fuel and the rest.
  • Traits, named as in the game.
  • Repair every frigate.

Exocraft

Cargo and technology for each exocraft you've summoned.

  • Each exocraft (Roamer, Nomad, Colossus, Pilgrim, Nautilon, Minotaur…) with a model from your game.
  • Technology and cargo with all the inventory tools, including Supercharge slots on the freighter's technology.
  • Add exocraft learns the geobay blueprints for the ones you don't have yet.

Companions

Your creature companions: names, size, trust, temperament and mood.

  • A picture of each companion: the desktop app draws its model from your game files, with the head, wings and tail it was born with. You can also use Change picture to pick one of your in-game screenshots (photo mode works well) or any image. The picture shows in the companion list too, so you can tell them apart at a glance.
  • Name, size, and whether it's a predator or has fur.
  • Trust and temperament: trust, helpfulness, aggression and independence.
  • Mood: hunger and loneliness.
  • Fed, happy and fully trusting in one click.
  • Creature battles: its type (Tropical, Frost, Fire, Toxic, Desert, Radioactive or Anomalous), which comes from the kind of world it was found on. Some species always have the same type, for example every robot is Mechanical; for those the type is greyed out. Its three stat classes (health, agility and combat effectiveness) are rolled by the game; tick Set the stat classes here to choose them, or press Make every stat S class.
  • Add a companion and Unlock every slot.

Bases

Your bases and the settlements you run or have visited.

Bases

  • Each base: name, type, part count, where it is (with Open in Coordinates) and who built it.
  • Copy parts and Paste parts between bases, Load parts from a file, Save to a file.
  • Add a prefab from the Base Building App (.nmsprefab).
  • Load from a .blend… reads an NMS Base Builder file. LiveLink works for bases too. See Blender.
  • Add to favourites keeps the base in your favourite places, with its spot on the planet, so you can warp back from any save. Settlements have it too.
  • Most used parts, and Delete base.

Settlements

  • Owned: settlements you run. Name, stats (population, happiness, production, upkeep, sentinels, debt, alerts and bug attacks), perks with Remove the negative perks, and Clear debt, alerts and bug attacks.
  • Visited: settlements you've been to. They belong to other players, so they're shown but never changed.

Storage

Base storage containers and the other standalone inventories in the save.

  • Storage containers 0 to 9, and other storage (chests on bases, lockers and the rest), from the two lists at the top. Show all lists everything.
  • Every container has the full set of inventory tools.

Cargo

Every stack in every inventory in one place: find where things are, gather them together, and tidy partial stacks.

  • Find any item across exosuit, ships, freighter, exocraft and storage.
  • Consolidate: pick a destination, choose Only items it already has if you like, and untick anything to leave alone. Matching stacks are topped up first, then free slots are used, taking the smallest stacks first. Special lockers are left out unless you include them.
  • Drag and drop stacks between any slots and inventories on any page. Technology always stays in its own inventory.

Knowledge

The blueprints you can build and the alien words you know.

  • Technology, recipes and base parts, and cosmetics and specials: search what you know, Learn… anything new, or Forget it.
  • Learn all technology and Learn all base parts add everything your game lists that the save doesn't know yet.
  • Words: how many you know for each race, word by word. Learn every word, every race, or all of one race's words.

Rewards

Every expedition reward, past and current, plus Twitch drops and platform rewards.

  • Expeditions, newest first, with how many of each one's rewards you have. Unlock this expedition's rewards, or tick single rewards.
  • Twitch drops and platform rewards in their own tabs.
  • Unlock all rewards unlocks every expedition reward and Twitch drop at once.
  • Platform rewards (a Nintendo Switch pre-order and The Game Awards) are checked by the game against the store you play on. On PC the game takes them out again, so Unlock all rewards leaves them alone.

Getting them in the game

  1. Quit No Man's Sky to the desktop. The game only reads rewards when it starts, and writes its own copy back whenever it saves. Saving rewards while it runs means they're undone.
  2. Press Save rewards to the game. Rewards live in an account file shared by all your saves, so they have their own save button.
  3. Start the game, load any save, and claim them from the Quicksilver Synthesis Companion on the Space Anomaly.
If the game changes them backThe editor watches the account file. If the game writes it again with fewer rewards than you saved, it tells you how many and why.
Rewards that won't claimSome unlocked rewards from older expeditions, eggs and multi-tools in particular, may do nothing when you try to claim them, even with free slots. That comes from the game, not your save: the slots the editor empties are the same as the game's own empty slots. Ships and decorations claim normally.

Standing

Your reputation with each race and guild, and the journey milestones the game counts.

  • Standing with the Gek, Korvax and Vy'keen, the guilds, outlaws and the Space Anomaly, with the game's rank names. Max on each, or Max every standing.
  • Journey milestones: warps, distance walked, aliens met, words learned and the rest.

Difficulty

The game's difficulty settings, the same ones as its options menu, including those it only lets you pick when starting a new game.

  • Preset, and whether settings are locked in the game.
  • Survival, combat, crafting and resources, inventory and travel: every setting, with the game's own choices.
  • Make everything easy and Back to normal set them all at once.

Item names

Where item names, icons and descriptions come from: your own copy of the game.

  • The item library is built from your No Man's Sky files the first time the app starts, kept on your PC, and rebuilt after game updates. Nothing from the game comes with the editor.
  • If Steam doesn't find the game, paste its folder (the one with GAMEDATA) and press Use this folder, then Rebuild from the game.
  • Goatfungus's item database (NMSSaveEditor.jar) works as a stand-in until your library is built. Search this PC for it finds it.

Raw data

Every value in the save, for when no other page has what you need.

  • Readable names for the game's short keys, with the original key beside each one.
  • Search keys and values, open any branch, and edit any value.
  • Export JSON and Import JSON for the whole save.
Careful here.Raw data changes anything, including things the game doesn't expect. Keep a backup before big edits (one is made each time you save).

Inventories and find

Tools that work the same on every page.

Inventory grids

  • Technology / Cargo / Both: the game's own inventories in the game's order, with icons, names and amounts. The grid keeps the game's columns, since slot position matters for adjacency bonuses.
  • Add an item: click an empty slot and type part of its name (Carbon, Orbital Exocraft Materialiser, Pulse Engine…). Press Enter or click a result and it goes into that slot as a full stack of the size your game uses there. Cargo can take anything. A technology grid only offers the technology that fits it: suit tech in the exosuit, multi-tool tech in a multi-tool, freighter tech in the freighter, and each kind of ship and exocraft its own (living ships, Sentinel interceptors, corvettes, Nautilon and Minotaur included). Show all technology lifts that. Procedural upgrades get their own seed. Add by item ID is there too.
  • Click a filled slot to change the amount, replace the item, fill the stack, repair or recharge it, or remove it.
  • Right-click any slot for a quick menu: Fill stack or Recharge, Repair, Copy, Duplicate, Supercharge, Move to another inventory (technology only where it fits) and Remove. On an empty slot: Add an item… and Paste; on a locked one, Unlock. Right-click inside a selection to do it to every selected slot.
  • Drag and drop stacks. Drag a box across the grid from an empty slot to select several and move them together.
  • Unlock all slots, Fill stacks, Repair, and Size and class to resize the inventory or change its class.
  • Supercharge slots on exosuit, starship, multi-tool, freighter and exocraft technology. Supercharged slots get a steady border; the arcs only move when you point at them.

Find anything

Press Ctrl K, or click the box at the top of the sidebar, and type. Results cover ships, multi-tools, bases, frigates, companions, settings, pages and every item in your inventories. Pick one to jump straight to it.

Light and dark

The sun or moon button at the bottom of the sidebar switches the look. By default the editor follows your Windows setting.

Blender

Real corvette renders, builds read straight from .blend files, and LiveLink: save in Blender, and the build is in your save.

What you need

  • Blender 4.2 or newer.
  • For corvettes: Charon Forge, installed as a Blender extension.
  • For bases: NMS Base Builder.

The editor finds them on your PC. If it doesn't, open Cover settings (on the Garage or the Dock Yard) and point it at Blender.

Corvette renders

  • Render all corvettes on the Garage, Render corvettes in the Dock Yard and on Starships, or Render again for one.
  • Renders are kept on your PC by build, so a build is only rendered once.
  • Automatic renders (Cover settings): a few seconds after a save opens, corvettes without a picture are rendered one at a time.
  • Render the other angles adds front, side, back and top views, picked under the cover.

Load from a .blend

Load from a .blend… on Shipwright (corvettes) or Bases reads the build from a .blend file, without you opening Blender. The editor works out which corvette or base the file is for, asks before changing it, and remembers the file for LiveLink.

LiveLink

  1. On Shipwright (or Bases), press Get the Blender add-on and install it in Blender (Edit, Preferences, Add-ons, Install from disk).
  2. Pick a corvette or base and press Turn on for this corvette. The editor offers to open the .blend it was last built from (Open in Blender), or Choose another.
  3. In Blender, the 3D view's sidebar has a LiveLink tab that shows the link. Set which corvette or base the file is for.
  4. Build. Each time you save the file (or press Send now), the build goes into your save. The editor backs up the save each time, and a card at the top of its window says what arrived.
The wrong corvette guardEach .blend remembers which corvette or base it's for. If a build arrives for a different one, the editor asks before writing it anywhere.

Close No Man's Sky before LiveLink writes, and reload the save in the game to see the result.

The LiveLink panel also has Your traveller: Import my traveller and Save the pose as a picture. See Exosuit.

Updating the add-onThe editor updates itself, but Blender keeps the add-on you installed. When a new add-on comes out (the What's new list says so, and the LiveLink panel in Blender shows "A newer add-on is ready"), press Get the Blender add-on again and install it over the old one.

Browser version

nms-save-editor.html is the same editor as a single web page for Chrome or Edge, for when you can't run the desktop app.

  • Folder mode: choose your NMS folder or the st_… folder inside it. Saving keeps a copy of the old pair in _editor_backups first. Chrome won't open AppData from a web page, so you may need to copy the folder somewhere else first.
  • File mode: drop both files (saveN.hg and mf_saveN.hg). The edited pair downloads, and you copy it back.
  • Not in the browser: the Dock Yard, renders, LiveLink and reading your game's files. For item names it uses Goatfungus's NMSSaveEditor.jar.

Questions

Answers to the things people ask most.

Windows says the app might be unsafe.
The program isn't code-signed, so SmartScreen warns once. Choose More info, then Run anyway. The source is public on GitHub.
My change didn't show up in the game.
Close the game before saving, then load the save again. If Steam Cloud put an older copy back, let it finish syncing first, or choose the local files when it asks.
How do I undo a save?
Every save makes a backup first. See Getting an old save back.
Item names show as codes, or icons are missing.
The item library hasn't been built yet, or couldn't find the game. Open Item names, check the game folder and press Rebuild from the game.
A corvette has no picture.
Without Blender, corvettes show a hologram of their parts. Install Blender and Charon Forge for real renders (see Blender).
Can I move a ship from one save to another?
Yes. Every ship from every save you open is in the Dock Yard's Hangar. Open the other save, find the ship and press Load ship into game….
I exported a ship. Where did it go?
To Documents\Harmonious Save Editor\Exports. The folder opens with the file selected each time you export.
My old taskbar pin opens a second button, or shows Edge's icon.
It's a pin from before the editor had its own window. Unpin it, open the editor, then right-click its taskbar button and choose Pin to taskbar. See Getting started.
A companion shows an egg, or looks wrong.
Companions are drawn from your game's own creature models. If one can't be found it shows an egg. Use Change picture for a screenshot, and press save creature files for the developer under the list so it can be fixed.
Does the editor need the internet?
No. It only goes online to check for updates, to fetch art from a listing link when you ask, and for links you click.
Is it safe for my account?
The editor only changes your own save files on your PC. Edits that make a save impossible in normal play (such as unlocking things) are your choice; keep backups if you play online with others.
