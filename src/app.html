Use a different folder

Open your save files

In your st_… save folder, press Ctrl+A to select everything, then open. You can also drag the whole st_… folder here. Edited files come back as downloads to copy into that folder.

Or edit a copied folder in place

Chrome won't open folders inside AppData. If you copy your st_… folder somewhere else, the editor can save straight into that copy, keeping a backup of each file it replaces.

Steam saves live in %APPDATA%\HelloGames\NMS\st_<your Steam ID>. Press Win+R and paste %APPDATA%\HelloGames\NMS to get there. On GOG the last folder is DefaultUser. Close the game before copying edited files back.
